# ACE-SEMESTERS
A full-stack student blogging platform built with Django for sharing semester-wise experiences, study resources, and tips to foster a collaborative academic community.


## ACE Semesters: Student Blogging & Resource Sharing

ACE Semesters is a full-stack web application built with Django, designed as a community-driven platform for students. It allows users to create accounts, publish posts about their semester experiences, share study tips, and upload resources. Key features include secure user authentication, full CRUD (Create, Read, Update, Delete) functionality for posts, and dynamic category-based filtering to easily find relevant academic content.

## About ACE Semesters



ACE Semesters is a full-stack student blogging and resource-sharing platform designed to foster a collaborative academic community. The project aims to solve the common challenge students face in finding relevant, peer-vetted information for their specific courses and semesters. By creating a centralized hub, students can share valuable knowledge, offer advice, and support one another's academic growth.

### Key Features:

* **Secure User Authentication:** Users can sign up, log in, and log out securely to manage their content.
* **Full Post Management (CRUD):** Authenticated users can create, edit, and delete their own blog posts, giving them complete control over their shared content.
* **Dynamic Content Filtering:** Posts are organized by categories (e.g., "Semester 3," "Data Structures," "Exam Tips"), allowing users to quickly filter and find the exact information they need.
* **Community-Driven Content:** The platform is built for students, by students, ensuring the shared resources and experiences are relevant, timely, and practical.

### Tech Stack:

* **Backend:** Django
* **Frontend:** HTML, Tailwind CSS, JavaScript
* **Database:** SQLite (Development), PostgreSQL (Production-ready)

## Project: ACE Semesters

ACE Semesters is a full-stack blogging platform built to help students succeed together. It provides a space for users to share semester-specific advice, post subject resources, and write about their academic journey. The goal is to create a community-driven knowledge base that makes navigating university life easier for everyone.

**Core functionality includes:**
* User registration and login system.
* Create, edit, and delete posts (authors only).
* Filter all content by subject or semester categories.

This project was built using **Django, HTML, CSS, JavaScript,** and **SQLite**.
